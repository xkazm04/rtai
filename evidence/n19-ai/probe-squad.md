## Gate results

- The three probe commands exited 0 with zero script errors and zero unknown arguments. Both brain choices reached the objective in every run.
- The selected GUT command passed all 14 tests. The selected scenario command passed all 13 scenarios. The runner discovers `scenario_*.gd` by filename.
- `quick.mjs --no-clash` passed engine parsing, format and style checks before the implementation commits. Early checks caught a Variant method call and a discarded return value. Both were corrected.
- A pre-commit attempt with an overridden temporary directory and merge-lane environment failed four tooling tests that exercise those settings. With the normal tooling environment the staged checks passed, including the tool tests.
- Full `lint.mjs` passed 18 of 19 checks. The required single flag line takes `project/boot/launch_args.gd` from its baseline of 201 lines to 202. The reproducible arena session uses ArenaArgs for the production option, so the fight and its replay can run independently of the shared launcher's declaration.
