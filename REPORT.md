2. **The feed's dead-flip scan runs in C++ (item 2).** `CitySim.scan_dead_flips`, cfdb53e4, the script loop kept as the no-DLL fallback. Micro only, debug editor binary, synthetic 400 people: ~22 us against 115-423 us (`evidence/perf/n10-scan/`). Its own share is not separated at the bench.
3. **The release riot at combo (item 3), both cuts together, against main 9bbe6d0a: frame p50 -0.485 ms (3.079 -> 2.620, -15.8 %, CI95 -0.538 to -0.427) and -0.91 s of a run's CPU (-10.6 %), lower in 30 of 30 rounds**, with an A/A control of the same code in the same rotation at +0.004 ms (CI95 -0.026 to +0.027). Instrument: CPU seconds from `GetProcessTimes` plus each run's own frame p50, three release exports in a rotating order, under `bench.lock` (`evidence/perf/n10-cputime/r30/`, table in LEDGER "Item 3 again"). The release's rig timer: p50 0.969 -> 0.586 ms (30 of 30), which carries most of the frame gain; timers the change does not touch (sim step, render CPU) are flat. **Not a quiet run**: 0-8 other Godot processes, median 2. This replaces the earlier -1.14 ms from 6 contended wall-clock pairs (`evidence/perf/n10-riotc/`, 6 of 6, rig p50 1.665 -> 0.957 ms), which overstated the size.

4. **The feed's fill runs in C++ (item 4, idea 1), the new baseline, ef31d9d4.** Release riot at combo against the pre-fill head, CPU seconds, 24 rounds with an A/A twin: frame p50 -0.235 ms (2.724 -> 2.537, -8.6 %, CI95 -0.302 to -0.174, lower in 21 of 24), CPU -0.63 s (22 of 24) (`evidence/perf/n10-cputime/fill/`, LEDGER "idea 1 again"). CONTENDED, 4-14 others. The A/A itself read +0.044 ms on this run (interval excludes 0), about a fifth of the effect. The script loop stays as the no-DLL fallback.
