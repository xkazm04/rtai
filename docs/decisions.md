- [2026-11-02] DECISION test-framework (TST-02): **GUT 9.7.1** wins over gdUnit4 v6.2.3. The shootout ran on stock 4.7.2 headless with this repo's warnings-as-errors set, one unit test and one scene/input test each, 3 runs each:
  - gdUnit4 v6.2.3 (latest release; v7 with official headless support is unreleased): refuses headless (exit 103) unless `--ignoreHeadlessMode`. Its fluent asserts return a value, so under `return_value_discarded=2` every `assert_x(...).is_y(...)` is a parse error (exit 105) until each test file opts out with `@warning_ignore_start("return_value_discarded")`. After that, 2/2 pass in 2.1-3.0 s, and a planted failure exits 100. Loud on parse errors (good). 516 files, 2.1 MB.
  - GUT 9.7.1 (targets 4.7.x): headless by default. `assert_eq` returns void, so tests compile under the full warning set with no opt-out. 2/2 pass in 1.5-2.8 s (scene input via `GutInputSender`), and a planted failure exits 1. **Hazard:** a test file that fails to parse is skipped with "Nothing was run" and exit 0. `tools/tests/run_unit.mjs` closes it: any SCRIPT ERROR/Parse Error line, or zero tests, fails the run (planted parse error proven to fail). 259 files, 3.0 MB.
  - Why GUT: it is the only one that keeps tests under the same strict warnings as game code, it runs headless without an override, and its 4.7.x pin is published. Re-check at gdUnit4 v7.0 release or any GUT bump.

- [2026-11-02] DECISION strict-warnings idioms: under `return_value_discarded=2`, `PackedStringArray.append` and `Signal.connect` return values, so use typed `Array[String]` (append is void) and check `connect` results.
